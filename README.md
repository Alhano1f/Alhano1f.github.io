# alhano1f.github.io

Personal website of **Alhanouf Aldossary**: *A Mind Beyond One Discipline.*

Live at **https://alhano1f.github.io**

A static, dependency-free site (HTML + CSS + vanilla JS) served by GitHub Pages.

| File | What it holds |
|---|---|
| `index.html` | All page content: landing, memories, who I am, credits, journey, pick a side, contact |
| `styles.css` | Design tokens (black / off-white / electric blue), layout, responsive + reduced-motion rules |
| `script.js` | Scroll-driven scenes, starfield, dot sphere, counters, section label |
| `assets/` | AL logo, favicon, social preview image, self-hosted fonts (Anton, Instrument Serif, IBM Plex Mono, DM Sans; SIL Open Font License) |

## Editing content

Text lives in `index.html`. The flying "memory" cards are the `MEMS` list near the top of `script.js`.

Commit to `main` and GitHub Pages redeploys in about a minute.
